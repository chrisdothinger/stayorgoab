# Source Discovery Prompt

Find public sources relevant to one hardened public question, not just a broad subject label. Prefer official and primary sources, but do not stop at the base packet when a dossier needs a stronger public argument.

Before source discovery, check `content/topic-question-registry.yml` and `docs/topic-question-standard.md`:

- confirm the topic is phrased as a public question;
- check the `question_family` for overlap/repetition;
- if the registry marks the topic `merge_candidate` or `split_candidate`, do not treat it as ready for full dossier migration until the question is resolved;
- prioritize high-sensitivity, unique, high-reader-value questions.

Use separate source lanes for new or substantially refreshed dossiers:

1. **Base packet:** primary law, official records, institutional reports, court decisions, and durable context.
2. **Pro-source lane:** credible current sources that help the strongest fair pro-independence argument understand its own evidence and answer objections.
3. **Anti-source lane:** credible current sources that help the strongest fair anti-independence/pro-federation argument understand its own evidence and answer objections.
4. **Counterargument scan:** enough cross-reading that pro and anti writers do not strawman each other.

Return source records only after checking title, publisher, URL, source type, accessed date, summary, stance, reliability category, how used, and related topic slugs. Mark advocacy, journalism, polling, legal commentary, government, court, and primary-law sources distinctly.
