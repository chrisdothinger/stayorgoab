## Bottom line

Neutral now lives in the overview. This legacy page is kept so old `/neutral/` links still resolve while the main dossier answer appears on the Overview tab.

The balanced answer is that Alberta could build or negotiate security arrangements, but the transition would be a major state-capacity test. Defence, border enforcement, federal policing, emergency management, intelligence coordination, and critical-infrastructure protection would need continuity plans before independence could be treated as operationally safe [3], [4], [6], [7], [8].

## What each side gets right

The pro-independence side is right that Alberta could prefer security institutions designed around Alberta’s geography, energy infrastructure, rural public safety, border relationships, and emergency risks [5], [8].

The anti/pro-federation side is right that Canada’s existing security architecture is deep and layered. It is not only a budget line. It includes national defence, border services, federal policing, emergency coordination, and relationships with other governments [3], [4], [6], [7].

## What survives both arguments

The useful middle is not mushy. Security continuity is a pass/fail issue. A credible transition plan would say which functions continue under agreement with Canada, which functions Alberta takes over immediately, which functions are phased, who pays, and what happens if negotiations fail.

The safer the negotiated continuity, the stronger the independence case. The more unilateral and vague the handoff, the stronger the federation-side caution.

## What would change the answer

- A published Canada-Alberta security transition agreement.
- A costed Alberta plan for defence, federal policing replacement, border services, emergency management, and critical infrastructure.
- Public positions from Canada, the United States, or allied partners on interim security cooperation.
- Draft Alberta legislation assigning command authority, funding, staffing, and emergency powers.
- Independent review of transition timelines and service-continuity risks.

## The practical test

The practical test is whether Alberta can show a no-gap security map. That map would separate day-one functions from long-term ambitions. It would also say which Canadian agencies remain involved during transition, which Alberta bodies take over, and how conflicts of authority are avoided.

A reader should be skeptical of both extremes. Alberta is not incapable of building security institutions. But Canada’s current security architecture is not something a new state can safely improvise after the fact. The source-backed question is therefore what agreements, laws, budgets, staffing, and fallback plans exist before transition begins.

## What readers should demand

Readers should ask for named institutions, not abstract confidence. A useful security plan would include defence posture, border services, federal-policing replacement, emergency-management continuity, intelligence-sharing assumptions, critical-infrastructure protection, and an explicit fallback if Canada refuses a preferred arrangement.

Until those details exist, both optimistic and pessimistic claims remain partly speculative. The safest public wording is conditional: possible with serious planning and negotiated continuity, risky without them.

## Practical checklist

Use the overview as the main answer. Use this legacy synthesis only as a compatibility note for old links.

Readers should ask whether a security claim names the operational function, the responsible institution, the transition authority, the budget, and the fallback. If those pieces are missing, the claim is still political confidence rather than a transition plan.
