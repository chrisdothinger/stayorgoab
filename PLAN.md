# StayOrGoAB Build Plan

Goal: Build StayOrGoAB as a beautiful, mobile-first, public-GitHub-native, fully autonomous, non-partisan civic research website about Alberta independence and the referendum process.

Execution phases:

1. Repository and scaffold.
2. Mobile shell and design system.
3. Content model and seed data.
4. Topic search and dossier UX.
5. Public auditability layer.
6. Agent workflow scaffolding.
7. Launch polish.

The active repository is the user-approved fallback `chrisdothinger/stayorgoab`.
