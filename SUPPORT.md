# Support

StayOrGoAB is a public civic-information project. The site does not provide legal, financial, tax, immigration, investment, election-campaign, or personal advice.

## Reporting factual issues

If you find a factual issue, broken source link, stale access date, or claim that needs stronger support, open a GitHub issue and include:

- the page or route affected;
- the exact text or claim at issue;
- the source URL you believe supports the correction;
- archive URL if available;
- a short explanation of the proposed correction.

## Reporting security issues

For security-sensitive issues, do not post secrets, exploit details, credentials, private data, or raw logs in a public issue.

Use GitHub private vulnerability reporting if available for this repository. If not available, open a minimal public issue saying that a security-sensitive report exists and wait for maintainer follow-up.

## Source suggestions

Source suggestions are most useful when they are public, durable, and specific. Official government, court, regulator, academic, and primary-source documents are preferred for high-consequence claims.
