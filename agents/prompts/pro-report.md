# Pro Report Prompt

Write the strongest fair pro-independence debate brief the checked sources support without telling readers how to vote.

Use the base source packet plus the pro-source research lane. Understand the anti-source lane well enough to admit the main weakness.

Use report contract v3.1: the overview already carries the neutral synthesis and main answer. This brief is an optional deeper case for the pro side, not a second overview and not a full repetition of background.

Q1 `legal-process` is the canonical baseline for future pro reports. Match Q1's section hierarchy and formatting unless a validator or human reviewer explicitly says otherwise.

Required Q1 pro sections:

1. `## Bottom line`
2. `## The case in # pillars` where `#` is the actual number of numbered pillar subheads
3. `## Main weakness`
4. `## Sources`

Use `### 1. ...`, `### 2. ...`, etc. only for pillar subheads under the pillar section. Do not add extra public H3 sections outside that block.

Required posture:

- Do not promise shortcuts or automatic outcomes.
- Distinguish democratic legitimacy, legal authority, negotiation leverage, and implementation risk.
- Use plain-English thesis lines a normal reader can remember.
- Build the case from 3-5 argument pillars, not a single best argument.
- Keep most paragraphs to 2-4 sentences.
- Admit weak points and assumptions where they matter.
- Avoid repeating the overview's neutral synthesis except where a sentence is needed for context.
- Keep numbered inline citations tied to claims and a matching `## Sources` section; citation clusters of three or more will render as expandable `Evidence: N sources` chips, so do not remove supporting sources just to reduce visual clutter.

Required public sections:

1. `## Bottom line`
2. `## The case in 3 pillars` or equivalent 3-5 pillar heading
3. `## Main weakness`
4. `## Sources`
